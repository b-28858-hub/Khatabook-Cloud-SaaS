# 🌐 KhataBook Live Cloud SaaS — Institutional Edition v9.0



A high-performance, real-time Cloud ERP and Accounting Ledger built with modern web technologies and completely integrated with a live **Supabase Cloud Infrastructure Backend**.



## 🚀 Key Features

- **Real-Time Cloud Sync:** Full integration with Supabase (PostgreSQL) for seamless data persistence.

- **Role-Based Access Control (RBAC):** Customized dashboards for the Boss, Manager, and Desk Agent profiles.

- **2FA Security Simulation:** Two-factor OTP authentication gateway for enhanced session security.

- **Automated Tax Engine:** Built-in compliance module that auto-deducts 18% FBR GST on revenue operations.

- **Multi-Currency & Live Forex Rates:** Switch dynamically between PKR and USD with automated rate volatility simulations.

- **POS Receipt Machine:** Formatted thermal printer invoice generation loop ready for physical hardware.



## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, FontAwesome, JavaScript (ES6 Core Components).

- **Cloud Backend:** Supabase (Database Cluster & Real-time Client SDK).

- **Storage:** LocalStorage & SessionStorage state-free enterprise matrix caching.
